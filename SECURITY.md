# Security

LocalWeave is an early-stage local application. Until a private reporting channel is published, report potential vulnerabilities without including secrets, personal data, vault excerpts, recordings, transcripts, or machine-specific paths.

Security-sensitive changes should be documented in `docs/security/`, assigned a permission tier, tested for denial and containment, and recorded as an architecture decision when they change a boundary.

Do not include secrets, personal data, Markdown vault excerpts, recordings, transcripts, models, indexes, audit logs, screenshots of private content, or machine-specific paths in reports or examples.

Before any future remote or collaboration workflow, define a private reporting channel and a credential-rotation procedure.
