# Integrations

## Stage 1

- Markdown vault Markdown.
- Local filesystem reads scoped to the configured vault.
- Local derived index.
- Local voice-note queue and transcription adapter.

## Later

- GitHub read-only/project handoff.
- Calendar read-only.
- Gmail draft-only.
- Conversational voice.
- Controlled file/application opening.

## Long-Term

- User-approved analysis from explicitly selected local data exports.
- Financial data read-only with stronger controls.
- Smart home as a future idea only after permission and audit systems are mature.
