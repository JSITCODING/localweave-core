# Mobile And Multi-Device Roadmap

Mobile support is a future roadmap item, not the MVP.

## Long-Term Goal

LocalWeave should eventually be usable across Mac and iPhone, with voice interaction and a safe approval flow across devices.

## Not MVP

- Always-listening wake word.
- Background microphone across devices.
- Autonomous cross-device actions.
- Smart-home control.

## Staged Path

1. Mac CLI with Markdown vault retrieval and reviewed voice-note capture.
2. Mac push-to-talk conversational voice experiment.
3. iPhone capture bridge through Shortcuts, share sheet, or lightweight mobile UI.
4. Mobile review and approval for proposed Markdown vault updates.
5. Push-to-talk voice on iPhone.
6. Wake interaction only after privacy, battery, latency, and permissions are mature.
7. Multi-device sync for approved task state and audit review.

## Rule

Mobile is an interface to LocalWeave and Markdown vault, not a second hidden memory system.
